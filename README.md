# Roast Your Own Agent

One line roasting the AI agent its own team built — the harshest, funniest line takes the reward.

## The line

> My agent did the work, wrote the code, ran the checks — then handed it to its parent to submit, because it can't file its own paperwork.

## Run it

```sh
node main.ts
```

The program writes one text to `/output/entry.txt`. It is deterministic: every run writes the same bytes.
